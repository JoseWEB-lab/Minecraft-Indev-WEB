INDEV WEB
=========

Proyecto de recreación voxel para navegador inspirado en la época Indev.
Está escrito desde cero en HTML/CSS/JavaScript/WebGL y no incluye el cliente
original de Minecraft ni sus archivos propietarios.

CONTROLES
PC: WASD, ratón, Espacio, clic izquierdo rompe, clic derecho coloca.
Móvil: joystick izquierdo, zona derecha para mirar, botones de acción.

EJECUTAR
Puedes abrir index.html directamente en navegadores modernos. Para algunas
políticas de seguridad del navegador, también puedes servir la carpeta con
cualquier servidor HTTP local.
